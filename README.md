# Jeong, index.html은 웹 브라우저에서 바로 실행되는 디지털 신호 처리(DSP) 신호 합성, 푸리에 변환(FFT) 스펙트럼 분석 및 디지털 필터 시뮬레이터입니다. 이 프로그램은 사인파, 코사인파, 구형파, 톱니파, 처프 스윕 파형과 AM 변조 프리셋을 조합해 신호를 만들고, 고주파 간섭 및 가우시안 백색잡음을 더한 뒤, 다양한 윈도우 함수와 버터워스·이상적 디지털 필터를 적용해 그 결과를 실시간으로 분석합니다. 사용자는 1단 시간 영역 차트, 2단 FFT 스펙트럼 차트, 3단 복원 파형·위상·STFT 스펙트로그램 탭과 주요 피크·RMS·SNR·MSE·THD 같은 정량 지표를 확인하면서, 신호를 Web Audio API로 재생하거나 CSV 및 PNG 파일로 저장할 수 있습니다.
# 사용하려면 먼저 index.html 파일을 웹 브라우저로 열고, 상단 프리셋을 누르거나 왼쪽 제어 사이드바(좁은 화면에서는 왼쪽 상단 메뉴 버튼으로 열기)에서 샘플링 주파수, 지속 시간, 신호 성분, 노이즈, 필터 파라미터를 조절하면 됩니다. 이어서 차트 위에 마우스를 올려 세부 값을 살펴보고 시간 창 슬라이더와 3단 차트 탭을 전환해 변화를 비교한 뒤, 상단 재생 버튼으로 소리를 듣거나 CSV·PNG 버튼으로 결과를 내려받으면 됩니다.
